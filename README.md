# Buy Assistant

We want a tool that helps find listings for things we are interested in buying, sometimes used.

The assistant should:

- track a list of open items to buy, and offer an easy way to add/modify details, including:
    - shipping zip code, default to home
    - target price
- monitor and track pricing, aggregated and/or in a timeline, including for archived listings
- notify us when a new listing for the item appears
- generate the complete price, including tax & shipping
- track some preferences without restating on every item, for example:
    - highly prefer natural fibers in clothing
    - highly prefer non-plastic items
